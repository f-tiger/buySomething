# 选品站策略简报（调研汇总）

> 汇总自三份调研报告（`docs/research/`）：竞品格局、爆款赛道、买家痛点。
> 定位一句话：**"中国先行信号 + 采购决策数据"的精选站，而不是又一个供应商目录。**

## 1. 定位与差异化（vs Alibaba.com）

| 维度 | Alibaba / Accio | 趋势间谍工具（Minea/PipiAds/Kalodata） | **本站** |
|---|---|---|---|
| 信号来源 | 供给目录（噪音大） | 西方平台已发生的广告/销量（滞后 4–8 周） | **中国本土先行信号（抖音/1688/小红书）→ 领先西方 4–12 周** |
| 商品数量 | 2 亿+（选择瘫痪） | 数百万（数据库式） | **每周 20–50 个人工精选深度卡片** |
| 价格信息 | 单一标价、需询盘 | 无供给侧价格 | **三层价差：1688 工厂价 vs Alibaba 价 vs 欧美零售价** |
| 决策数据 | 无 | 广告数量 | **生命周期评分（早期窗口/成长/饱和）+ 季节窗口 + 到岸成本计算器（含 2026 关税）+ 合规护照** |
| 合规 | 免责声明 | 无 | **US/EU 分列认证清单、GPSR 责任人提示、召回雷区** |

核心壁垒：语言与数据壁垒（西方团队看不懂抖音/1688）+ 人工可信精选 + 中立立场（Accio 是阿里自家引擎，不会推荐 1688 一手价）。

## 2. 目标用户

Amazon FBA 卖家、Shopify 品牌、TikTok Shop 卖家、精品零售商、小型批发商（US/EU）。
2025 关税剧变后的共同转向：从直邮小包 → 批量海运+海外仓；从最低单价 → 最优到岸成本+合规确定性。

## 3. 收录赛道（14 个，三层结构）

- **利润款（主推）**：LED/红光美容仪、智能宠物用品、AI 玩具/陪伴机器人、阳台光伏/储能配件（欧洲）
- **流量款（引流）**：CleanTok 家居清洁、保温杯/水具、发型工具、康复按摩器械、露营装备、厨房小工具、3C 差异化配件、收纳
- **心智款（调性）**：马面裙/新中式服饰、中国茶文化与茶具

## 4. 每张商品卡的数据字段（买家愿望清单驱动）

1. 中国先行信号（何时何地在中国爆的，现处生命周期哪一段）
2. 三层价差（1688 / Alibaba / 欧美零售）+ 1688 中文搜索词（可复制）
3. 真实 MOQ 区间
4. 到岸成本计算器（EXW × 数量 → 关税 → 头程 → 到岸单价 → 毛利率）
5. 合规护照（US/EU 分列 + 难度分级 + GPSR 提示）
6. 季节窗口 + 最晚下单月份
7. 雷区提示（该品类召回/差评主因）
8. 物流模式建议（海运/空运/是否含电）

## 5. 后续路线图（本期不实现，规划参考）

- MVP（本期）：静态精选站，24+ 深度商品卡 + 计算器 + 合规/关税信息
- V1：每周更新机制（"本周雷达"）+ newsletter 订阅漏斗
- V2：1688 代理对接（发现→执行闭环，服务佣金变现）
- V3：验厂报告/第三方 QC 预订、欧盟 GPSR 责任人打包服务合作入口
