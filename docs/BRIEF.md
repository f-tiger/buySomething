# 迭代 Brief：实时化 + 商业化（2026-08-22）

> 用户原话：可以监控谷歌 trends，不做盲目调研，实时化。另外差异化和如何创造营收？
> 以下为优化后的执行版需求。

## 1. 实时化（Google Trends 监控）

- 每个商品定义英文 Google Trends 查询词（`trendQuery`），欧洲品类用对应 geo（DE）
- GitHub Actions 每日定时拉取近 90 天热度，计算动量（近 14 天 vs 前 60 天，±15% 分级），产出 `trends.json` 自动提交
- 站点：卡片动量徽章（↗/→/↘）、详情页迷你曲线 + 更新时间 + Google Trends 验证链接
- 数据缺失/失败：保留上次数据或降级为纯编辑评级，不伪造

## 2. 差异化（一句话）

**双边信号雷达**：中国侧先行信号（抖音/1688，领先 4–12 周）× 西方侧实时验证（Google Trends 动量）。
广告间谍工具缺中国侧，Alibaba/Accio 缺中立验证。

## 3. 营收

- Free（获客）→ Pro $29/月（决策数据订阅，对标 Thieve $15–49 已验证区间）→ Sourcing Desk 代采佣金 5–8%（执行闭环护城河）
- 辅助：合规/物流服务转介、newsletter 赞助
- 红线：不做供应商付费上榜

详见 `docs/STRATEGY.md` 第 5–7 节。

# 迭代 Brief v2：广度调研 + 落地（2026-08-22 第二轮）

> 用户原话：再深度优化一轮 prompt，调研更加广。/ 优化 prompt 再执行，执行到网站，上线到我的网站还是需要单独购买域名？

## 优化后的执行版需求

六个互不重叠的调研模块，每模块定义"研究问题→必须产出→改变什么决策"：
- **A 数据源扩展**（抖音/1688/小红书/TikTok CC/Keepa/ImportYeti/Kickstarter/Reddit 的接入方式、成本、ToS 风险）→ 管线 V2 优先级
- **B 获客增长**（社区版图、SEO 空档、newsletter 打法、转化基准）→ 90 天获客计划
- **C 买家细分**（六类买家规模/工具支出/付费意愿；$29 验证；佣金基准）→ 首发客群与定价
- **D 法务风险**（爬虫判例、Trends ToS、价格情报、FTC 披露、推荐责任、资金传输、UFLPA、商标）→ 立即落地的护栏
- **E 赛道二波+证伪**（10 个新赛道验证 + 对现有 24 品对抗性证伪）→ 商品增删
- **F 地理扩展**（DE/FR/ES/IT/PL/AU/中东/拉美对比）→ geo 路线图

执行要求：结论落回产品——报告入 docs/、可立即落地的（P0 管线修复、组合增删、护栏、部署）直接实施推送。

## 上线与域名

- 不需要单独购买域名即可上线：GitHub Pages 免费提供 `f-tiger.github.io/buySomething`（自动 HTTPS），部署 workflow 已加入仓库
- 自定义域名（如 sourceradar.io，约 $10–12/年）是可选升级：在域名商购买后，GitHub Pages / Cloudflare Pages 均可免费绑定并签发证书
